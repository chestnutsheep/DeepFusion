# 宏观-中观-微观分析逻辑传导框架

| 层级          | 核心组件        | 关键考察因子与指标                                              | 核心逻辑与洞察                                 |
| :---------- | :---------- | :----------------------------------------------------- | :-------------------------------------- |
| **宏观驱动层**   | 技术革命周期      | • 全要素生产率(TFP)<br>• 关键领域VC/PE投资额                        | 定义长期赛道：识别技术革命阶段，决定未来产业格局。               |
|             | 货币与信用周期     | • 美联储资产负债表<br>• 主要政策利率                                 | 决定全球流动性：宽松期推高估值，紧缩期进行压力测试。              |
|             | 增长与通胀周期     | • 全球PMI<br>• 美国CPI/PCE                                 | 定位周期阶段：判断资产轮动的宏观背景。                     |
|             | 地缘政治与思潮     | • 地缘风险指数(GPR)<br>• 重大政策纲领                              | 改变游戏规则：引发供应链重构与行业监管变化。                  |
| **中观市场状态层** | 整体风险偏好      | • VIX指数<br>• 信用利差                                      | 度量市场情绪：恐慌时市场只认可最确定性的内核。                 |
|             | 结构性特征       | • 行业收益率离散度(CV)<br>• 板块轮动速度                             | 诊断市场健康度：低CV代表共识强，高CV代表共识破裂。             |
| **微观资产表现层** | 根本内核(Alpha) | • ROIC(投资资本回报率)<br>• 营收与现金流增速<br>• 资产负债率<br>• 毛利率与市场份额 | 识别核心价值：资产长期生存能力与内在价值的决定性因素。             |
|             | 市场定价(Beta)  | • P/E, P/B, P/S<br>• 北向资金/基金流量                         | 评估市场价格：市场为Alpha支付的价格。机会源于Alpha与Beta的错配。 |
| **传导与放大机制** | 政策与制度       | • 产业政策<br>• 金融改革(如注册制)                                 | 直接改变行业盈利模式与估值逻辑。                        |
|             | 投资者异质性      | • 机构/个人持仓比例<br>• 基金申赎数据                                | 机构行为研究驱动，个人行为情绪驱动，共同放大市场波动。             |
|             | 反身性         | • 估值历史分位数                                              | 价格变化会自我强化，形成正反馈或负反馈循环。                  |

## 使用逻辑
1.  **定位(Zoom Out)**：从宏观驱动层开始，识别当前1-2个主导市场的核心驱动力
2.  **诊断(Zoom In)**：观察中观市场状态，判断市场所处的风险偏好与结构性特征
3.  **决策(Focus)**：在微观层寻找根本内核优秀且市场定价合理的资产
4.  **验证(Check)**：通过传导机制检验逻辑的完整性，考虑政策、投资者行为与反身性影响

## $$R = R_f + β_i  ✖️(E(R_m) - R_f)$$

-  **$E(R_i)$：某资产（如股票）的预期收益率** 
  一定程度上可视为  :  **特质性Alpha (α)**。 <br> **• 来源**：微观资产表现层中的根本内核<br> **• 盈利能力**：[[ROE]]、[[ROIC]]、[[毛利率]] <br>**• 增长质量**：营收增长、盈利增长持续性 <br> **• 财务健康**：负债率、现金流、偿债能力 <br> **• 商业模式**：竞争优势、护城河、定价权



- **$R_f$：无风险利率（通常用国债收益率）**
  <br> **• 含义**：理论上的最低收益基准<br> **• 构成要素**：国债收益率 <br> • 货币时间价 <br>• 通胀保值债券(TIPS)


- **$β_i$：系统性风险溢价**
<br> 衡量资产的系统性风险（跟市场同涨同跌的程度）

|         β系数         | 含义  |     驱动因素     |    Concrete     |
| :-----------------: | :-: | :----------: | :-------------: |
| $β_m × (R_m - R_f)$ | 市场  |   [[宏观驱动]]   |     技术革命周期      |
|                     |     |              |    全球货币与信用周期    |
|                     |     |              |    经济增长与通胀周期    |
|                     |     |              |    地缘政治与社会思潮    |
|      $β_s × S$      | 风格  | [[中观]](市场状态) | 市场整体风险偏好（贪婪/恐惧) |
|                     |     |              | 市场结构性特征（共识/分歧）  |
|      $β_v × V$      | 估值  | [[微观]](市场定价) |     估值水平变化      |
|                     |     |              |     资金流向效应      |
 
       
### ** 残差项 (ε)**

- **包含内容**：
    
    - 传导与放大机制效应
        
    - 政策/制度冲击
        
    - 投资者异质性行为
        
    - 反身性反馈效应
        
    - 不可预测的随机噪声
