# 第一章：财务基本面内部检验
目的：验证公司的盈利质量是否扎实，经营是否健康，是否存在财务数据的“水分”或“粉饰”。
## 验证逻辑（理论支撑）
1. 盈利现金保障倍数：利润表上的净利润是“应计制”下的产物，可能包含大量应收账款或非现金收益。只有经营活动现金流才是企业真金白银的造血能力。若净利润持续高于经营现金流，需警惕利润虚增。
2. 营收现金回收率：销售商品收到的现金与营业收入的比例，反映回款能力和收入确认的谨慎性。持续低于1可能意味着信用政策激进或渠道压货。
3. 周转效率：应收账款周转天数与存货周转天数反映了企业对下游的议价能力和库存管理能力。这两个指标的突然拉长，往往是经营恶化的先行信号。
4. 毛利率趋势：毛利率是企业产品竞争力与成本控制能力的综合体现。其变化方向（连续上升/下降）比绝对数值更重要。

## 行动步骤
### 1.  收集数据
获取目标公司过去3-5年的年度（每个报告期）及季度关键财务指标、利润表、资产负债表、现金流量表并提取以下指标（优先获取现成指标，如数据源未提供现成数据则根据定义计算）。
- 营收同比增长率
- 毛利率 = (营业收入 - 营业成本) / 营业收入
- 净利率 = 净利润 / 营业收入
- ROE = 净利润 / 平均净资产
- 盈利现金保障倍数 = 经营活动现金流净额 / 净利润
- 营收现金回收率 = 销售商品提供劳务收到的现金 / 营业收入
- 应收账款周转天数 = 365 / (营业收入 / 平均应收账款)
- 存货周转天数 = 365 / (营业成本 / 平均存货)
### 2. 制作趋势图表
将上述指标绘制成时间序列图，观察变化方向。
### 3. 结果分类讨论

| 观察到的现象           | 可能的解读                         |
| ---------------- | ----------------------------- |
| 盈利现金保障倍数持续 > 1   | 利润含金量高，造血能力强                  |
| 盈利现金保障倍数持续 < 0.7 | 利润可能只是“纸面富贵”，需结合 应收账款周转天数 判断  |
| 营收现金回收率持续 < 1    | 收入确认可能偏激进，或回款周期在拉长            |
| 应收账款周转天数连续上升     | 对下游议价能力可能变弱，或通过放宽信用政策刺激销售。    |
| 存货周转天数连续上升       | 产品可能出现滞销，或管理层对需求过于乐观导致备货过度。   |
| 毛利率连续下滑          | 产品竞争力下降、成本上升、或行业竞争加剧          |
| 毛利率上升但周转天数同步大幅上升 | 可能是以放宽信用或压货为代价的短期增长，需警惕后续业绩变脸 |
