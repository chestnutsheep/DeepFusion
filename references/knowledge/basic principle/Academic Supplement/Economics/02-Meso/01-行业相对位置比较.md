# 01-行业相对位置比较

> 整合版：跨界比较的坐标系与硬核评分体系

---

## 一、核心论点

**高增速不必然构成安全边际**，真正的信息优势来自确认"**行业所处周期位置与跨界相对估值**"。
逻辑链条：
- 高增速≠高回报（价格可能已透支估值）
- 信息差的来源不是更难获得的数值预测，而是**跨界比较的坐标系**
- 超额回报来自：你能判断**这个增速在这个周期位置是否被高估/低估了**

---

## 二、跨界比较的坐标系

### 纵向维度（时间轴）
在同一行业内，比较公司当前估值相对于历史中枢的位置。

### 横向维度（截面轴）
在同一时间点上，跨行业比较公司估值相对于其他行业的相对位置。

### 综合判断
只有将纵向（历史分位）和横向（跨行业溢价/折价）结合起来，才能判断一个行业的估值究竟是"贵得合理"还是"便宜得有坑"。

---

## 三、分析工具（硬核版）

### 3.1 两柱表结构

| 行业名称 | 预期增速 | 当前行业PE | 5Y PE中位数 | PE分位数 | 预期PEG | 历史PEG |
|:---|:---|:---|:---|:---|:---|:---|
| 白酒 | 15% | 28x | 30x | 40% | 1.87 | 2.0x |
| 光伏 | 30% | 18x | 25x | 20% | 0.60 | 0.83x |
| 半导体 | 25% | 45x | 50x | 35% | 1.80 | 2.0x |
| 医药 | 18% | 35x | 40x | 30% | 1.94 | 2.2x |

### 3.2 坐标系解读

#### X轴：历史PE分位数（估值温度）
- 低于25%分位 → 疑似低估
- 25%-75%分位 → 合理区间
- 高于75%分位 → 疑似高估

#### Y轴：预期PEG（性价比）
- PEG < 1.0x → 高性价比（增速未被充分定价）
- PEG 1.0x-2.0x → 合理区间
- PEG > 2.0x → 低性价比（增速已充分/过度定价）

#### 四象限定位法

| | 低分位（<25%） | 高分位（>75%） |
|:---|:---|:---|
| **PEG<1.0** | 🟢 最佳击球区：低估+高性价比 | 🟡 关注：高景气但估值已高 |
| **PEG>2.0** | 🔵 价值陷阱：便宜但有隐忧 | 🔴 高风险区：泡沫区间 |

### 3.3 相对PE Band分析

在同一坐标系下，绘制目标行业与可比行业的PE Band曲线，识别：
- **相对PE溢价**：目标行业PE / 可比行业PE > 1.5 → 需解释溢价来源
- **相对PE折价**：目标行业PE / 可比行业PE < 0.7 → 检查是否被系统性低估
- **收敛/发散趋势**：相对PE的变化方向（均值回复 vs 趋势性偏离）

## 四、增强阅读机制：四大穿透规则

### 规则1：量在价先（同步指标法）
**观察产能利用率和产品价格指数的同步变化：**
- 量价齐升 → 行业景气上行 ✅
- 量增价跌 → 行业出清或过度竞争 ⚠️
- 量缩价升 → 供给受限或垄断提价 ⚠️
- 量价齐跌 → 行业景气下行 ❌

### 规则2：库存"迭代"信号（领先指标法）
**区分库存在不同行业下的含义：**
- 制造业库存 → 被动补库=周期顶部信号；主动去库=周期底部信号
- 消费库存 → 渠道库存高位+终端动销放缓=危险信号
- 科技库存 → 芯片交期缩短=需求放缓领先指标

### 规则3：财务数据交叉验证（滞后指标校验）
**使用毛利率、现金流、ROE三个指标交叉验证：**
- 高营收增速+毛利率下降 → 以价换量，需警惕
- 高利润增速+经营现金流恶化 → 利润质量存疑
- ROE提升+杠杆率上升 → 区分是经营改善还是财务技巧

### 规则4：一致性检查（排除记分卡）
**如以下4项全不一致，即使数值好看也判为"暂时搁置"：**
- 产能利用率 vs 营收增速 → 方向是否一致
- 库存水平 vs 毛利率 → 库存堆积是否伴随毛利挤压
- 资本开支 vs 自由现金流 → 投资是否在创造价值
- 分析师预期 vs 实际数据 → 是否存在系统性乐观偏差

## 五、系统化嵌入（硬核版）

### 五个步骤的闭环

| 步骤 | 内容 | 输出 |
|:---|:---|:---|
| **1. 行业初筛** | 基于两柱表的客观定量比较 | 初筛排名表 |
| **2. 量价验证** | 规则1: 产能+价格同步信号 | 景气状态标签 |
| **3. 库存迭代** | 规则2: 库存含义解读 | 库存周期位置 |
| **4. 财务校验** | 规则3: 毛利率+现金流+ROE | 利润质量评分 |
| **5. 终审裁决** | 规则4: 一致性检查 | 通过/搁置/否决 |

### 信息使用决策树

```
两柱表初筛 → 是否在最佳击球区？
   ├── 是 → 量价验证是否支持？
   │   ├── 是 → 库存信号是否安全？
   │   │   ├── 是 → 财务校验是否通过？
   │   │   │   ├── 是 → ✅ 纳入核心观察池
   │   │   │   └── 否 → ⚠️ 标记风险点，等待下一期数据
   │   │   └── 否 → ⚠️ 等待库存信号改善
   │   └── 否 → 🚫 暂不纳入
   └── 否 → 标记「关注」但不操作
```

## 六、动态更新机制

### 定期维护节奏
- **周度**：更新行业PE、相对PE Band
- **月度**：更新行业预期增速（基于分析师一致预期变化）
- **季度**：完整重跑五步闭环（财报季后）

### 动态调整规则
- 行业初筛排名变化 >3 位 → 触发深度复查
- PEG 跨区间变化（如从 <1.0 变为 >2.0）→ 立即触发预警
- 相对 PE 溢价/折价 >2σ 偏离 → 重点关注
- 出现"利率-汇率-大宗"同步异动 → 触发宏观情景重估

---

## 七、投资含义与风险管理

### 组合构建含义
基于行业相对位置比较的结果，形成行业**超配/标配/低配**建议，并结合后续章节的微观验证完成个股层面落地。

### 风险边际
- 单一行业的判断出错不可避免
- 跨行业比较的最终目的是**持续做出概率占优的决策**
- 通过分散+动态调整来控制单一判断失误的影响
