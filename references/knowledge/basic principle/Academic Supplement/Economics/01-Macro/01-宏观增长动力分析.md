## 分析框架

### 经济增长阶段判断
```mermaid
graph LR
    A[衰退期] --> B[复苏期]
    B --> C[扩张期]
    C --> D[过热期]
    D --> A
```

## 判断标准：

- 复苏期：PMI从低位回升至==50==以上，工业增加值加速
- 扩张期：多项指标同步改善，投资消费双旺
- 过热期：通胀压力显现，政策开始收紧
- 衰退期：PMI跌破50，企业利润下滑


## 监测重点：

· 三驾马车（消费、投资、净出口）贡献度变化
· 月度数据与季度数据的交叉验证
· 预期管理与实际数据的差距

## 1.1 经济增长模块 (economic_growth)，

### 1.1.1 国内生产总值 (GDP)
接口名称：get_gdp_yearly
功能描述：获取国内生产总值数据，包含总体绝对增量/同比和第一二三产业的绝对值/同比增长
参数：
update (bool)：是否强制更新数据，默认False（优先使用本地数据）
返回值：pd.DataFrame - 国内生产总值数据
保存接口：save_gdp_yearly(df, output_format="CSV")

### 1.1.12 分析功能
接口名称：calculate_gdp_gap
功能描述：计算GDP增长缺口，公式：GDP增长缺口 = 实际GDP增速 - 潜在增长率

参数：
update (bool)：是否强制更新数据，默认False（优先使用本地数据）
返回值：dict - 包含GDP增长缺口相关数据的字典
接口名称：analyze_pmi
