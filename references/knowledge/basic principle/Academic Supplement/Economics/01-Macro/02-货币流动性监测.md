# 货币流动性监测

## 核心指标体系

| 指标           |     | 数据源                                 | 观察要点    | 政策含义   |
| ------------ | --- | ----------------------------------- | ------- | ------ |
| **M2货币供应**   |     | `ak.macro_china_money_supply()`     | 广义流动性总量 | 货币政策松紧 |
| **社会融资规模**   |     | `ak.macro_china_social_financing()` | 实体经济融资  | 信用环境   |

|              |     |                                     |         |        |
