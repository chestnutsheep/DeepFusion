# 第一章 财务基本面内部检验
## 一、核心验证逻辑
>核心矛盾：**<font color="#9bbb59">权责发生制 vs 收付实现制</font>**

净利润是"应计制"下的账面产物，可能包含大量应收账款或非现金收益；只有经营活动现金流才是企业真金白银的造血能力，两者的差异是识别财务水分的关键。
## 验证逻辑（理论支撑）

1. 盈利现金保障倍数：利润表上的净利润是“应计制”下的产物，可能包含大量应收账款或非现金收益。只有经营活动现金流才是企业真金白银的造血能力。若净利润持续高于经营现金流，需警惕利润虚增。
2. 营收现金回收率：销售商品收到的现金与营业收入的比例，反映回款能力和收入确认的谨慎性。持续低于1可能意味着信用政策激进或渠道压货。
3. 周转效率：应收账款周转天数与存货周转天数反映了企业对下游的议价能力和库存管理能力。这两个指标的突然拉长，往往是经营恶化的先行信号。
4. 毛利率趋势：毛利率是企业产品竞争力与成本控制能力的综合体现。其变化方向（连续上升/下降）比绝对数值更重要。

| 指标类型  | 具体指标               | 核心作用              |
| ----- | ------------------ | ----------------- |
| 利润含金量 | 盈利现金保障倍数           | 衡量净利润转化为真金白银的能力   |
| 收入真实性 | 营收现金回收率            | 反映回款能力和收入确认的谨慎性   |
| 运营效率  | 应收账款周转天数、存货周转天数 | 体现对上下游议价能力和库存管理水平 |
| 盈利能力  | 毛利率趋势              | 综合反映产品竞争力与成本控制能力  |

## 二、标准化行动步骤

1. **数据收集**：获取目标公司过去3-5年的86项核心财务指标

>[!Note]+ 指标清单
> - 营收同比增长率
> - 毛利率 = (营业收入 - 营业成本) / 营业收入
> - 净利率 = 净利润 / 营业收入
> - ROE = 净利润 / 平均净资产
> - 盈利现金保障倍数 = 经营活动现金流净额 / 净利润
> - 营收现金回收率 = 销售商品提供劳务收到的现金 / 营业收入
> - 应收账款周转天数 = 365 / (营业收入 / 平均应收账款)
> - 存货周转天数 = 365 / (营业成本 / 平均存货)

2. **数据清洗**：标注连续3个报告期为空的指标，图表绘制时排除
3. **结构可视化**：绘制主要财务指标及其二级分项的饼图，直观体现贡献度
4. **趋势分析**：绘制核心指标的时间序列图，重点关注连续3期以上的变化趋势

## 三、 结果分类解读

|观察到的现象|可能的解读|
|---|---|
|盈利现金保障倍数持续 > 1|利润含金量高，造血能力强|
|盈利现金保障倍数持续 < 0.7|利润可能只是“纸面富贵”，需结合 应收账款周转天数 判断|
|营收现金回收率持续 < 1|收入确认可能偏激进，或回款周期在拉长|
|应收账款周转天数连续上升|对下游议价能力可能变弱，或通过放宽信用政策刺激销售。|
|存货周转天数连续上升|产品可能出现滞销，或管理层对需求过于乐观导致备货过度。|
|毛利率连续下滑|产品竞争力下降、成本上升、或行业竞争加剧|
|毛利率上升但周转天数同步大幅上升|可能是以放宽信用或压货为代价的短期增长，需警惕后续业绩变脸|

# 第二章 行业相对位置比较
## 一、核心验证逻辑
1. **相对估值原则**：股票的"贵贱"不能只看绝对PE/PB，必须与行业可比公司对比。成长性高于行业平均的估值溢价合理，反之则存在高估风险。
2. **超额增速原理**：个股营收增速减去行业平均增速，代表公司攫取市场份额的能力，持续为正说明竞争力强于行业整体。
3. **杜邦分解对比**：通过与行业均值对比ROE的三大驱动因子（利润率、周转率、杠杆率），判断公司高回报是靠"硬功夫"还是"加杠杆"。
4. **离散度参照**：计算行业指标标准差，判断个股与行业的差距是否属于正常波动范围。

## 二、标准化行动步骤
1. **确定可比行业**：明确公司所属的申万二级或三级细分行业
2. **获取行业基准**：收集行业在营收增长率、ROE、PE/PB、杜邦三因子上的平均值和中位数
3. **计算行业标准差**：针对毛利率、ROE等核心指标，计算行业内的标准差（σ）
4. **计算超额/差值序列**：
	- 超额营收增速 = 个股营收增速 - 行业平均营收增速
	- 超额ROE = 个股ROE - 行业平均ROE
	- 相对PE折溢价 = (个股PE - 行业中值PE) / 行业中值PE × 100%
	- 杜邦因子差值 = 个股因子值 - 行业平均因子值
5. **制作趋势图表**：将上述指标绘制成时间序列，并标注±1σ的"正常波动带"

## 三、结果分类解读
| 观察到的现象 | 可能的解读方向 |
|-------------|---------------|
| 超额营收增速持续为正且位于+1σ上方 | 公司具备显著竞争优势，市场份额持续提升 |
| 超额营收增速为正但估值折价扩大 | 市场尚未充分反映公司成长性，存在预期差 |
| ROE高于行业且差值主要来自销售净利率 | 拥有品牌或技术壁垒，盈利质量较高 |
| ROE高于行业但差值主要来自权益乘数 | 高回报依赖财务风险，利率上行或行业下行期脆弱性高 |
| ROE低于行业但总资产周转率低 | 重资产扩张期可接受；成熟期则反映运营效率问题 |
| 超额指标在±1σ带内波动 | 个股表现与行业同步，缺乏显著α特征 |

# 第三章 机构行为与内部人信号验证
## 一、核心方法论
机构拥有研究优势，内部人（高管、大股东）拥有信息优势，他们的买卖行为往往领先于基本面数据的公开披露，可作为对基本面判断的印证或警示。

## 二、核心验证指标
- **北向资金**：外资通常被认为是长线价值投资者。持续净买入可能意味着国际资本对公司的认可。需特别注意“股价横盘但北向持续买入”的背离现象。
- **机构调研**：调研频率和参与机构的知名度，反映了专业投资者对公司关注度的变化。密集调研往往发生在公司基本面出现积极变化的前夜。
- **十大股东/流通股东变动**：知名公募、私募、社保、QFII的“新进”或“大幅增持”是较强的正面信号；反之，“清仓式减持”是重大警示。
- **高管增减持**：高管最了解公司真实经营状况。持续增持（尤其是多名高管集体行动）是极强的信心信号；持续减持（尤其是股价高位时）则需要高度警惕，即使当时财报数据依然亮眼。
- **融资融券余额**：融资余额增长代表市场做多情绪高涨，但也可能积累踩踏风险；融券余额异常增长代表强烈的看空预期。

## 三、标准化行动步骤
1. 收集该股近3个月、6个月的<font color="#953734">北向资金</font>累计净买入额及持仓占比变化趋势
2. 统计近6个月的机构<font color="#953734">调研次数</font>、<font color="#953734">参与机构总数</font>及<font color="#953734">头部机构参与情况</font>
3. 对比最近两期财报的<font color="#953734">十大股东/十大流通股东</font>名单，标记"新进""增持""减持""退出"的机构
4. 统计近6个月高管及<font color="#953734">关联方的净增持/减持金额</font>及行动时间点
5. 观察融资余额的<font color="#953734">月度环比</font>变化

## 四、结果分类解读
| 观察到的现象                | 可能的解读方向                     |
| --------------------- | --------------------------- |
| 北向资金持续净卖出+基本面数据尚可     | 外资可能看到了财报未体现的风险，需警惕         |
| 机构调研频率突然大幅增加          | 公司可能出现积极变化，机构密集跟踪验证         |
| 调研后十大股东出现新进知名机构       | 调研验证了看好逻辑，机构用真金白银投票         |
| 多名高管集体大额增持            | 内部人对未来信心极强，股价可能被低估          |
| 高管在股价高位持续减持           | 即使财报亮眼，内部人可能认为估值已充分反映价值     |
| 北向资金连续 3 个月净买入 + 股价滞涨 | 外资在悄悄吸筹，市场可能尚未充分反应价值。       |
| 机构调研频率突然大幅增加          | 公司可能出现积极变化，机构在密集跟踪验证。       |
| 调研后十大股东中出现新进的知名机构     | 调研验证了机构看好逻辑，用真金白银投票。        |
| 融资余额快速攀升              | 市场做多情绪高涨，但若后续资金接力不足，容易发生踩踏。 |
