## 1.3 交叉验证机制（内部逻辑一致性）

*除了看孤立指标，还需要检查指标之间的逻辑自洽*：

🟢- 毛利率上升 + 应收账款周转天数上升：以放宽信用为代价换取高价，不可持续 → 触发“黄灯警告”。
🟢- 存货周转天数上升 + 营收现金回收率下降：产品滞销且回款困难，典型衰退信号 → 触发“红灯”。
🟢- 盈利现金保障倍数<1 + 应收账款周转天数稳定：可能因存货增加或预付增加导致，需进一步分析现金流量表细项。


第二章：行业相对位置比较 —— 补充“超额信号的统计阈值与趋势判断”

你的框架已经有行业均值、标准差，但需要明确什么时候算“显著超额”，以及趋势的持续性如何量化。

2.1 显著性阈值设定

| 对比指标 | 弱超额 | 显著超额 | 极端超额 |
| :--- | :--- | :--- | :--- |
| **超额营收增速** | 5~10 bp | 10~20 个bp | >20 bp + 持续 4 个季度 |
| **相对 PE 折溢价** |-20 ~0 bp | -20~-50 bp | >+50bp +超额增速已回落 |
| **超额 ROE** | 2~5 bp | 5~10 bp | >10 bp + 杠杆贡献占比>60% |
| **杜邦因子差值**| +2~5 bp | +5~10 bp | >10 bp + 行业价格战激烈 |

**行业标准差σ**：取行业内所有公司（剔除亏损异常值）过去4个季度的滚动标准差:
1. 用±1σ作为“正常波动带”
2. ±2σ作为“极端偏离”。

2.2 趋势方向判断（超额序列的动量）

仅看当前值不够，需要看超额指标的变化方向：

 超额营收增速连续3个季度扩大 → 市场份额加速提升，强α信号。
 超额营收增速连续2个季度收窄 → 竞争优势边际减弱，即使仍为正，也应下调预期。
 超额ROE扩大但完全由权益乘数（杠杆）驱动 → 高风险，在宏观利率上行周期中需一票否决。

第四章：宏观周期定位 —— 补充“周期位置数值化与个股β敏感度匹配”

你已经有基钦、美林时钟的定性判断，但需要把“周期阶段”转化为可量化的调整系数，直接代入第一张的核心公式（λ 和 Δ）。

4.1 基钦周期阶段的量化映射

基钦阶段 Δ_cycle 取值区间 对个股估值容忍度调整
被动去库存（复苏初期） +0.2 ~ +0.5 可使用行业历史75%分位PE
主动补库存（繁荣期） +0.5 ~ +1.0 可使用行业历史90%分位PE（泡沫区）
被动补库存（衰退初期） -0.2 ~ -0.5 只能接受行业历史25%分位PE
主动去库存（萧条期） -0.5 ~ -1.0 只考虑现金大于市值或股息率>国债利率的标的

计算方法：使用华泰金工的周期拟合方法，或者简易地根据工业增加值与库存增速的差值符号判断。简单规则：

🟢- 需求↑ & 库存↓ → Δ=+0.3
🟢- 需求↑ & 库存↑ → Δ=+0.7
🟢- 需求↓ & 库存↑ → Δ=-0.4
🟢- 需求↓ & 库存↓ → Δ=-0.7

4.2 美林时钟的乘数因子 λ_sentiment

美林阶段 λ_sentiment 参考区间 对情绪乘数的影响
复苏期（GDP↑，CPI↓） 1.1 ~ 1.3 乐观情绪蔓延，成长股享受溢价
过热期（GDP↑，CPI↑） 1.3 ~ 1.6 极度乐观，但需警惕政策转向
滞胀期（GDP↓，CPI↑） 0.7 ~ 0.9 恐慌折价，防御板块相对抗跌
衰退期（GDP↓，CPI↓） 0.5 ~ 0.7 悲观过度，价值股可能出现黄金坑

注意：λ_sentiment 受行业β影响，周期性行业在过热期λ更高，在衰退期λ更低。

4.3 个股β系数的简易估算

🟢- 使用个股月度收益率与沪深300收益率回归，取过去36个月的Beta。
🟢- β > 1.2：强周期，Δ_cycle 对估值影响放大1.5倍。
🟢- 0.8 ≤ β ≤ 1.2：中性。
🟢- β < 0.6：弱周期/防御，Δ_cycle 影响减半。

修正后的周期调整公式（你在第一章写的那个公式的实操版）：

```
P_fair = E_fund × λ_sentiment × exp(β × Δ_cycle)
```

其中 Δ_cycle 采用基钦周期映射值（-1.0 到 +1.0），β 为个股贝塔。如果板块或个股有明确行业β，使用行业β替代个股β（减少噪音）。

5.1 多维度证据加权打分表

维度 权重 评分（-5到+5） 加权得分
财务内检（第一章） 30% [填写]

评分标准：

🟢- +5：强烈正面，所有子指标都指向最优区间。
🟢- +3：明显正面，多数子指标优于历史中位数。
🟢- +1：轻微正面，略好于中性。
🟢- 0：中性或信号矛盾。
🟢- -1 ~ -5：对应不同程度的负面。

总分对应的行动：

🟢- 加权总分 > +3：强烈看好，仓位可到8-12%（单票上限）。
🟢- +1 ~ +3：看好，仓位4-8%。
🟢- -1 ~ +1：中性或信号混乱，仓位0-2%或不参与。
🟢- < -1：回避或做空。

5.2 赔率-置信度矩阵（细化到具体数值）

你之前有定性表格，现在给出数字化的仓位公式（参照凯利公式变形）：

```
建议仓位比例 = (置信度 × 赔率 - (1 - 置信度)) / 赔率 × 最大仓位限制
```

其中：

🟢- 置信度 = 加权总分转换（总分+5对应置信度95%，总分+3对应70%，总分+1对应55%，0对应50%）
🟢- 赔率 = (乐观目标价 - 现价) / (现价 - 悲观目标价)，上限取5（若>5按5计）

最大仓位限制：根据你的风险偏好，单只股票不超过总资金的15%，行业不超过30%。

实操简化版：

置信度 赔率1.5 赔率2 赔率3 赔率5
55% 1% 2% 3% 4%
70% 3% 5% 7% 9%
85% 5% 8% 12% 15%

5.3 验证节点与纠错触发条件（具体数值化）

你在手册结尾列出了验证节点，但没有规定“多差才触发纠错”。建议：

验证指标 触发纠错的条件 纠错动作
下季度毛利率 下滑超过2个bp 减仓50%
应收账款周转天数 同比延长>15% 减仓50%，若连续两季恶化则清仓
北向资金 连续2个月净卖出 减仓30%，若伴随股价下跌则清仓
高管减持 单月净减持>500万元 减仓50%，若为董事长减持则清仓
宏观周期 基钦阶段转入被动补库存或主动去库存 整体仓位下调50%
股价 跌破关键支撑位（如60日均线） 无条件止损清仓

关键原则：任何单一触发条件都导致至少减仓30%，两个触发同时出现则清仓。不依赖“再等等看”。
