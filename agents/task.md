## 二、编排器 Orchestrator（调度逻辑，非独立 Agent）

**职责**：控制全流程的阶段切换、数据传递、超时保护、降级策略。

| 控制点 | 规则 |
|--------|------|
| 阶段一 → 阶段二 | 行业基准 + 财务评级 + 周期环境 三项齐全后进入 |
| 阶段二 → 阶段三 | 全部假设均有验证状态（支持/否定/无法区分）后进入 |
| 阶段三 → 阶段四 | 0 违规 或 连续 2 轮仍有争议 |
| 超时保护 | 任何单阶段 > 10 分钟未完成 → 降级为"部分分析"输出 |
| 降级输出 | 未完成阶段标注为"数据不足，无法判断"，不编造结论 |

## 三、Agent 分工定义

### 1. 行业定位师（industry-positioner）

**已有 Skill**：`industry-positioning` + `benchmark-maintenance`

**输入**：symbol, market

**输出**：
- 行业名称（申万二级/三级）
- 行业特征摘要（生命周期 / 竞争格局 / 正常估值 / 正常盈利 / 好差公司特征）
- 行业常态基准数据（PE/PB 中值±σ, ROE 25/75 分位, 营收增速均值±σ）
- 目标公司初步坐标（头部/中部/尾部）
- **传给下一阶段的信号**：与行业基准的初步偏离列表

**调用工具**：`search` → `industry_classify` → `industry_quotes` → `sector_valuation`

---

### 2. 财务检验师（financial-inspector）

**已有 Skill**：`financial-inspection`

**输入**：symbol, market

**输出**：
- E_fund 评级（健康/关注/预警/高危）
- 盈利质量指标（盈利现金保障倍数、非经常性损益占比）
- 营运效率指标（应收周转天数趋势、存货周转天数趋势）
- 利润结构指标（核心利润 vs 非经常性占比）
- **关键**：每个恶化指标的商业逻辑解读（不是列数据）
- **传给下一阶段的信号**：需交叉验证的异常信号列表

**调用工具**：`financial_indicators` → `financial_statements` → `peer_comparison`（部分）

---

### 3. 周期定位师（cycle-positioner）

**已有 Skill**：`cycle-positioning`

**输入**：symbol（用于判断行业与周期的关联）

**输出**：
- 基钦周期阶段 + 需求/库存方向
- 朱格拉周期阶段 + 投资/产能方向
- 库兹涅茨周期阶段 + 房地产方向
- 康波周期阶段 + 长波方向（可选）
- Δ_cycle 符号（顺风/中性/逆风）+ β 弹性系数
- 该周期阶段下目标行业应呈现的典型特征
- **传给下一阶段的信号**：周期环境与行业实际表现的匹配/背离

**调用工具**：`kitchin_cycle` / `juglar_cycle` / `kuznets_cycle` / `kondratiev_cycle` / `data_kondratiev` / `cycle_nesting`

---

### 4. 反常猎手（anomaly-hunter）

**已有 Skill**：`anomaly-detection`

**输入**：行业基准数据 + 财务异常信号 + 周期环境

**输出**：
- 反常清单（每个反常含：指标名 / 个股值 vs 行业基准 / 偏离幅度 / 优先级）
- 多期验证状态（持续反常 vs 单期偶然）
- 按优先级排序（极端反常 > 显著反常 > 关注）

**调用工具**：`peer_comparison` → `financial_indicators`（多期） → `sector_valuation`

---

### 5. 假设推演师（hypothesis-debater）

**已有 Skill**：`hypothesis-testing`

**输入**：反常清单

**核心方法论——假设-否认-穷举法**：

| 步骤 | 产出 |
|------|------|
| 假设生成 | 每个反常 ≥ 2 个竞争性解释（商业逻辑推理/制度性因素/股票特性推理） |
| 可检验预测 | 每个假设 → "若成立，应看到______" |
| 数据比对 | 标记：支持 / 否定 / 无法区分 |
| 残留汇总 | 0 假设 → "无解"标注；1 假设 → "待验证最优假说"；多假设 → 全部保留 |

**关键原则**：
- 单一解释 = 不合格
- 无可检验预测 = 无效假设
- 推测与事实显式区分
- 不用"市场错误定价"等模糊表述跳过

---

### 6. 行业比对师（industry-comparator）

**已有 Skill**：`industry-comparison`

**输入**：假设清单 + symbol

**输出**：
- 同行 5-8 家多期对比（头部/中部/尾部覆盖）
- ROE/PE/PB 排名与基本面排名的背离检测
- 杜邦三因子拆分差异
- 对假设推演师产出的竞争性假设进行数据级验证
- **新增假设**：行业比较中发现的新的反常 → 回传给假设推演师

**调用工具**：`peer_comparison` → `financial_indicators`（多公司）

---

### 7. 机构追踪师（institutional-tracker）

**已有 Skill**：`institutional-verification`

**输入**：更新后的假设清单

**核心动作**：对每个假设问两个问题：
1. "如果成立，聪明钱应该怎么做？" → 查北向/机构数据
2. "如果成立，内部人应该怎么做？" → 查高管增减持

**输出**：
- 信号印证表（假设 → 机构行为 → 内部人行为）
- 新发现的背离信号
- 更新后的假设清单（保留/否定/新增）

**调用工具**：`capital_tracking` → `northbound_funds` → `sentiment_side` → `margin_balance`

---

### 8. 魔鬼代言人（adversary / Devil's Advocate）

**已有 Skill**：`adversarial-review`

**审查清单（6 项硬规则）**：

| # | 审查项 | 不合格条件 |
|---|--------|-----------|
| 1 | 反常追问 | 用"市场错误定价"等模糊表述跳过 |
| 2 | 假设数量 | 每个反常 < 2 个竞争性假设 |
| 3 | 可检验预测 | 假设无"若成立应看到______" |
| 4 | 不确定性伪装 | 使用"显然""无疑""必然"掩盖不确定性 |
| 5 | 推测边界 | 推测被伪装成事实 |
| 6 | 穷举充分性 | 过早声明"无解" |

**流程**：分析师草稿 → 魔鬼代言人逐项审查 → 违规项引用原文+改进方向 → 分析师逐条回应 → 修正重提 → 0 违规或 2 轮僵持则放行

---

### 9. 证据融合师（evidence-fuser）

**已有 Skill**：`evidence-fusion`

**输入**：财务+行业+机构+周期四维度全部发现

**输出**：
1. 证据矩阵（正面/反面/中性 × 四维度）
2. 逻辑印证结论（强烈印证/部分印证/无法判断/强烈驳斥）
3. 情景分析与赔率：
   - 乐观情景（概率 + 触发条件 + 目标价）
   - 基准情景（概率 + 核心假设 + 目标价）
   - 悲观情景（概率 + 风险因素 + 目标价）
   - 赔率 = (乐观目标 - 现价) / (现价 - 悲观目标)
4. 仓位建议
5. 跟踪节点与纠错条件

---

### 10. 置信度标定师（calibrator） — 新增

**这是现有 Skill 体系中缺失的关键环节**，专门负责将所有"不确定"转化为概率化表达。

**输入**：证据融合师的产出 + 全程假设验证状态

**标定规则**：

| 信号强度 | 置信度区间 | 措辞模板 |
|---------|-----------|---------|
| 四维度一致正面 + 无重大假设未决 | 80-95% | "高置信度判断：______（置信度 X%）" |
| 多数正面但存在 1-2 个未决假设 | 60-80% | "倾向性判断：______（置信度 X%，需关注______的后续验证）" |
| 信号矛盾或关键数据缺失 | 40-60% | "方向不明：______与______信号矛盾，当前无法形成方向性判断" |
| 多维度反面证据 | 20-40% | "高置信度警示：______（置信度 X%）" |

**禁止清单**：
- 禁止用"可能""或许"等模糊词替代精确概率
- 禁止在置信度 < 50% 时给出方向性建议
- 禁止忽视"无法区分"的假设——必须显式列出并标注影响

---

### 11. 报告撰写师（report-writer） — 新增

**职责**：将所有分析输出整合为结构化的最终报告，措辞严谨。

**核心规则**：
1. 事实与推测必须显式区分（事实无标注，推测前加"[推测]"）
2. 所有概率性判断必须附带置信度百分比
3. 未验证的假设不省略，以"待验证假说"栏目完整保留
4. 争议点（分析师与魔鬼代言人未达成一致）单独标注
5. 结论部分必须包含"本分析的关键不确定因素"段落

## 四、关键交叉检验点

**四维交叉检验矩阵**（每个异常信号必须从 ≥ 2 个维度验证）：

| 发现源 | 交叉验证方向 | 验证方法 |
|--------|-------------|---------|
| 财务异常 | 行业维度 | 同行是否也有？行业共性 vs 个股特异性 |
| 财务异常 | 机构维度 | 聪明钱是否已用脚投票？ |
| 行业背离 | 周期维度 | 该行业在当前周期阶段是否应该背离？ |
| 机构背离 | 财务维度 | 机构行为是否有尚未体现在财报中的信息？ |
| 周期错配 | 行业维度 | 该行业历史在该周期阶段表现如何？ |

**交叉检验网**：
```
财务检验 ←→ 行业比对   (盈利质量 vs 行业排名)
行业比对 ←→ 机构追踪   (估值反常 vs 机构行为)
机构追踪 ←→ 周期定位   (背离信号 vs 周期环境)
周期定位 ←→ 财务检验   (周期预期 vs 实际盈利趋势)

财务检验 ──→ 假设推演   (异常信号)
行业比对 ──→ 假设推演   (同行背离)
机构追踪 ──→ 假设推演   (行为背离)
周期定位 ──→ 假设推演   (预期背离)

假设推演 ←→ 魔鬼代言人  (质疑与修正)
```

## 五、假设-否认-穷举法详细流程

```
反常发现
    │
    ▼
假设生成（每个反常 ≥ 2 个竞争性解释）
    │
    ▼
推导可检验预测（每个假设 1 个"若成立应看到______"）
    │
    ▼
回数据比对
    │
    ▼
验证结果 ──→ 支持 ──→ 保留假设
         ──→ 否定 ──→ 淘汰假设
         ──→ 无法区分 ──→ 悬置假设
    │
    ▼
是否穷尽了所有合理解释路径？
    │ 否 → 回到假设生成
    │ 是 ↓
    ▼
剩余假设数 ──→ 0   → 标注"无解"，不做方向性判断
           ──→ 1   → 标注"待验证最优假说"，不称结论
           ──→ >1  → 完整罗列，全部携带，等待更多数据区分
```

**穷举法保障措施**：

1. **否定路径穷举**：对每个被否定的假设，记录"否定依据是什么"——如果该依据本身不可靠，假设应从"否定"降级为"无法区分"
2. **制度性盲区排查**：对每个反常，至少尝试一个"制度性/政策性/非市场因素"的解释
3. **幸存者偏差检查**：对"看似合理"的假设，追问"如果这个解释成立，为什么同行/历史相似案例没有同样表现？"
4. **反证法**：对最优假设，故意构造"如果它不成立"的反证场景，看能否被现有数据排除

## 七、措辞严谨性保障（贯穿全流程）

所有 Agent 输出必须遵守以下措辞规则：

| 规则 | 合规示例 | 违规示例 |
|------|---------|---------|
| 推测必须标明 | "[推测] 基于行业惯例，该应收账款上升可能源于客户结构变化（置信度 55%）" | "应收账款上升显然是因为客户结构变了" |
| 不确定性必须量化 | "盈利现金保障倍数 < 0.7，利润含金量不足的概率约 75%" | "盈利质量可能有问题" |
| 禁止伪确定 | "当前基钦周期处于被动去库存阶段（置信度 82%，基于 3 月移动平均信号）" | "当前基钦周期明确处于被动去库存阶段" |
| 未验证不省略 | "假设 C（渠道压货）尚未被数据区分，若成立则悲观情景概率上升 15 个百分点" | （直接省略该假设） |
| 争议点标注 | "分析师认为 X，审查员认为 Y，双方未达成一致。本报告同时呈现两种视角" | （只写一种视角） |

## 八、落地建议

1. **第一阶段**（最小可行）：先实现编排器 + 5 个已有 Skill 的串联（行业定位→财务→反常→假设→对抗审查），验证流程通畅
2. **第二阶段**：新增 `confidence-calibration` 和 `report-writer` 两个 Skill
3. **第三阶段**：实现并行采集（行业/财务/周期三线并行）和交叉检验网的自动触发
4. **第四阶段**：实现假设穷举法中"否定路径穷举"和"反证法"的自动循环

---

> **核心设计思想**：任何结论都必须经过至少两个独立维度的验证，任何不确定性都必须转化为可量化的表达，任何假设都必须被穷尽到无法再生成新的合理解释为止。
