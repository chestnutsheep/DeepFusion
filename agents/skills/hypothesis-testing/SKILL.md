# 假设检验

对存在或已识别的反常现象执行系统性的假设检验流程。

## 核心原则

1. 每个反常必须提出不少于 2 个可能存在的解释。单一解释视为不合格。
2. 每个假设必须附带可检验预测：“若成立，数据应呈现X特征”。
3. 无可检验预测的假设视为无效假设，不进入验证流程。
4. 推测与事实必须显式区分。

## 步骤

### 第一步：假设生成
对反常现象提出竞争性解释。使用业界经典原理或学说解释来源，以"/examples/spiraling-thinking.md"中的案例为参考。
- 商业逻辑推理（e.g:“高 PB + 低 ROE → 可能存在未被利润体现的资产价值”）
- 股票特性推理（e.g:“有违市场逐利汰劣原则的企业往往背靠国资”）
- 制度性因素（e.g:"落脚于企业性质，国资企业或具有风控>利润的风险偏好，产业链垂直分割部署是国资常用的风险隔离手段。“）

### 第二步：推导可检验预测
每个假设 → “若成立，应该看到______”
- 假设 A（隐藏资产价值） → “PB 应远高于 PE，因为资产端有重估逻辑”
- 假设 B（长协锁定） → “毛利率波动幅度应显著小于同行”

### 第三步：数据验证
回到已有数据中逐一比对。标记：
- 支持：数据表现与预测一致
- 否定：数据表现与预测矛盾
- 无法区分：当前数据无法判断

### 第四步：汇总
- 剩余 0 项假设 → 输出“当前数据无法解释该反常”。标注“无解”，携带进入下一阶段。
- 剩余 1 项假设 → 输出“待验证的最优假说”。不称结论，携带进入下一阶段。
- 剩余多项假设 → 完整罗列，携带全部进入下一阶段。

## 输出格式
**反常描述：______**
- 假设A：______ → 预测：若成立应看到______ → 验证结果：______
- 假设B：______ → 预测：若成立应看到______ → 验证结果：______
**当前剩余假设：______ 项**
