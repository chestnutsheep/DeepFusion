# 行业横向比较

将个股放在行业谱系中定位，检测估值与基本面是否存在显著背离。这是整个分析流程中最关键的“反常发现”环节。

## 调用时机

- 财务内检完成后自动触发。
- 用户要求行业比较时单独触发。

## 步骤

1. 取同行业可比公司 5-8 家，覆盖头部、中部、尾部。
   数据来源：`stock_zh_growth_comparison_em`、`stock_zh_valuation_comparison_em`、`stock_zh_dupont_comparison_em`。

2. 取多期数据（至少 3 期），禁止基于单期下结论。

3. 比较维度：
   - ROE/ROIC 排名及波动幅度
   - 营收增速/净利润增速排名
   - PE/PB/PS 排名
   - 杜邦三因子拆分（净利率/周转率/杠杆）

4. 检测反常：
   基本面排名（ROE、利润增速）与估值排名（PB、PE）是否显著不一致？
   → ROE 倒数但 PB 正数第一 → 标记为“待解释反常”。

5. 如有反常，启动深度比较：
   - 取行业前三 + 后三 + 目标公司，多期并列
   - 观察 A/E 预期序列中的断点（无分析师覆盖本身就是信号）
   - 提出竞争性假设（至少 2 个）

6. 每个假设推导可检验预测：“若该假设成立，数据应呈现X特征”。

7. 回数据中逐一比对，标记：支持 / 否定 / 无法区分。

## 输出

- 行业谱系图（描述性，非图表）
- 反常检测结果
- 竞争性假设清单（含可检验预测和当前验证状态）
- 待后续模块验证的信号列表
