# 证据融合与综合决策

将财务、行业、机构、周期四个维度的发现整合为一个综合判断。

## 调用时机

- 前四个分析模块全部完成后触发。
- 这是 DeepFusion 分析流程的最终阶段。

## 步骤

### 第一步：证据矩阵
将四个模块的核心发现填入下表：

| 验证维度 | 正面证据（看好） | 反面证据（看空） | 中性/无法判断 |
|:---|:---|:---|:---|
| 财务内检 | | | |
| 行业比较 | | | |
| 机构行为 | | | |
| 周期定位 | | | |

### 第二步：逻辑印证结论
根据证据的数量、质量、一致性，给出倾向性判断：

- 强烈印证：核心命题均有正面证据支持，无重大反面证据，多维度信号共振
- 部分印证：有正面证据，但也存在难以解释的反面信号或不确定性
- 无法判断：证据不足、信号矛盾、或关键信息缺失
- 强烈驳斥：核心命题被反面证据直接推翻，或多个维度发出明确警示信号

### 第三步：情景分析与赔率
- 乐观情景：核心假设全部成立，估值目标
- 基准情景：部分成立，中性估计
- 悲观情景：核心假设被证伪，最差情况
- 赔率 = (乐观目标价 - 现价) / (现价 - 悲观目标价)

### 第四步：仓位建议
结合置信度与赔率，给出仓位参考。

### 第五步：跟踪节点
设定关键验证节点和纠错条件。

## 禁止

- 在数据不足以支撑方向性结论时，强行给出“买入/卖出”建议。
- 多个假设未被区分时选择最“像故事”的那个输出。
- 忽视反面证据，只呈现支持单一方向的证据。
