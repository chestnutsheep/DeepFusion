# 行业定位

在任何个股深度分析前，必须先完成行业定位。这一步为后续所有分析提供参照系。

## 调用时机

- 收到个股分析任务时，作为第一阶段自动触发。
- 行业常态基准库已存在 → 调取。不存在 → 先调用 benchmark-maintenance 构建。

## 步骤

1. 用 `search` 或 `stock_info` 确定目标公司所属行业（申万二级或三级）。
2. 调取 `industry_benchmark.db` 中该行业的常态基准数据：
   - 估值区间（PE/PB 中值、均值、标准差、历史分位数）
   - 盈利分布（ROE、毛利率、净利率的 25/50/75 分位）
   - 成长性基准（营收增速、净利润增速的行业均值及波动率）
   - 财务结构基准（资产负债率、资产周转率均值）
3. 输出行业特征摘要（≤5 句话），包含：
   - 行业生命周期阶段
   - 竞争格局（集中度、国资占比）
   - 正常估值范围
   - 正常盈利水平
   - 行业内“好公司”和“差公司”的典型财务特征

## 输出格式

- 行业名称与分类标准
- 行业特征摘要（≤5 句话）
- 目标公司在行业中的初步坐标（头部/中部/尾部）
- 当前数据时点与下次建议刷新时间
