# 宏观周期定位

判断当前宏观经济环境对目标公司所处行业是顺风还是逆风。

## 调用时机

- 机构行为分析完成后自动触发。
- 用户单独要求周期定位时触发。

## 步骤

1. 基钦周期定位：
   - 获取工业增加值同比增速（月度，3月移动平均平滑）
   - 获取工业企业产成品存货同比增速（月度，3月移动平均平滑）
   - 绘制象限：X = 需求增速，Y = 库存增速
   - 判断当前阶段：被动去库存 / 主动补库存 / 被动补库存 / 主动去库存

2. 朱格拉周期定位：
   - 获取固定资产投资完成额累计同比
   - 获取 GDP 不变价当季同比
   - 辅助：PMI、企业中长期贷款余额增速
   - 判断当前阶段：复苏期 / 繁荣期 / 衰退期 / 萧条期

3. 综合输出：
   - 当前周期综合环境：顺风（Δ > 0）/ 中性（Δ ≈ 0）/ 逆风（Δ < 0）
   - 该周期阶段下应重点关注的行业类型
   - 未来 6-12 个月的关键宏观跟踪指标
