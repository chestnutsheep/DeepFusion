# 反常检测

基于行业常态基准库，自动检测个股指标是否落在正常范围之外。

## 调用时机

- 在股票进行同行比较阶段触发。
- 用户单独要求检测某只股票的反常指标时触发。

## 步骤

1. 将目标公司的核心指标与行业常态基准逐一比对：
   - PE/PB/PS vs 行业中值 ± 1σ
   - ROE vs 行业 25/75 分位
   - 营收增速 vs 行业均值 ± 1σ
   - 毛利率趋势方向 vs 行业趋势方向

2. 标记偏离幅度：
   - 偏离 > 1σ → “关注”
   - 偏离 > 2σ → “显著反常”
   - 偏离 > 3σ → “极端反常，优先级最高”

3. 对反常按优先级排序。极端反常必须优先处理。

4. 输出反常清单，每个反常附带：
   - 指标名
   - 个股值 vs 行业基准
   - 偏离幅度
   - 优先级

## 注意

单期反常可能是偶然。必须用多期数据验证该反常是否持续存在。
单期反常 + 多期确认 → 可信反常。单期反常 + 历史正常 → 可能是一次性事件。
