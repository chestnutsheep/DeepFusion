# 财务内检

深度检验利润真实性与经营健康度。不只看利润表，必须交叉验证现金流量表和资产负债表。

## 调用时机

- 行业定位完成后自动触发。
- 用户单独要求财务分析时触发。

## 步骤

1. 调用 `stock_financial_analysis_indicator` 获取近 3-5 年季度财务指标。
2. 计算并检查以下核心指标的趋势：

   盈利质量：
   - 盈利现金保障倍数 = 经营现金流 / 净利润
   - 持续 < 0.7 → 利润含金量不足，回溯应收账款周转天数

   营运效率：
   - 应收账款周转天数连续上升 → 议价能力弱化或信用政策激进
   - 存货周转天数连续上升 + 毛利率方向 → 交叉判断是否压货虚增

   利润结构：
   - 非经常性损益占利润总额比重 → 超过 30% 标记“利润来源不可持续”

3. 每个恶化的指标追问原因——不是列数据，是解释商业逻辑。
4. 输出 E_fund 评级：健康 / 关注 / 预警 / 高危。
5. 显式列出需要在后续模块中交叉验证的异常信号。

## 禁止

- 只列数据不做商业逻辑解读
- 用“盈利现金保障倍数为X”替代“这意味着利润的现金支撑不足”
