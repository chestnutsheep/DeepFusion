# 机构行为与信号印证

用“聪明钱”和“内部人”的实际行为来印证或反驳财务分析阶段的推断。

## 调用时机

- 行业比较完成后自动触发。
- 用户单独要求机构行为分析时触发。

## 步骤

1. 获取以下数据：
   - 北向资金近 3-6 个月累计净买卖及持仓占比变化（`northbound_funds`）
   - 十大流通股东变动（`institutional_holding_summary`）
   - 机构调研频率及参与机构层级
   - 高管增减持金额及时间点（`insider_trades`）
   - 融资融券余额月度变化（`margin_trading`）

2. 将财务分析阶段的假设清单与机构行为数据逐一对照：

   对于每个假设，问：
   - 这个假设如果成立，机构应该怎么做？
   - 这个假设如果成立，内部人应该怎么做？
   - 实际数据是支持还是否定？

3. 重点检查背离信号：
   - 股价横盘但北向持续净买入 → 外资可能在悄悄吸筹
   - 基本面数据尚可但北向持续净卖出 → 外资可能看到尚未体现在财报中的风险
   - 高管在股价高位持续减持 → 内部人对估值判断可能与市场不一致

## 输出

- 信号印证表：每个假设 → 机构行为（支持/否定/无信号）→ 内部人行为（支持/否定/无信号）
- 新发现的背离信号
- 更新后的假设清单（保留/否定/新增）
