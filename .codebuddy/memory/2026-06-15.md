## ak_cache 缓存键污染 + 采集器增量补数据修复

### 问题
行业日行情采集 (`industry_daily_collect`) 的结果被 diskcache 缓存。
重跑时 `ak_cache` 命中缓存返回旧数据，数据库没补上新数据。

根因三层叠加：
1. `ak_cache` key 生成在 `pop("ttl")` 之前 → ttl/ttl2 污染缓存键
2. 采集器不检查 DB 新鲜度 → 每次全量拉取（含缓存命中）
3. 无 force 参数 → 无法主动绕过缓存

### 修复内容

| 文件 | 改动 |
|------|------|
| `deep_fusion/cache.py` | key 生成前先 pop ttl/ttl2/force；新增 force=True 参数；ak_cache_async 同步 |
| `deep_fusion/shared/industry_db.py` | 新增 get_daily_latest_date(code)、latest_trading_date() |
| `deep_fusion/data/sources/industry_collector.py` | DB新鲜度检查 + 增量起始日 + force 参数透传 |
| `deep_fusion/tools/industry.py` | industry_daily_collect 暴露 force 参数 |
