## 修复：中观热力图二级行业不画图 + 基钦相位名不一致

### Bug 1: 自选二级行业选取后不画热力图
- **根因**: `activeMatrix`/`activeDates` 的判断逻辑用了 `comboLevel`（来自 `heatmapConfig._comboLevel`），但自定义模式下 `heatmapConfig` 是 `CATEGORY_CONFIG.custom`，无 `_comboLevel` 字段，默认为 1，导致二级数据 `customMatrix`/`customDates` 从未被选用
- **修复**: 引入 `effectiveLevel = heatmapCategory === 'custom' ? customLevel : comboLevel`，用 `effectiveLevel === 2` 判断是否使用二级数据

### Bug 2: 组合模式保存二级行业时 l2Result 不触发
- **根因**: `l2Result` 的请求条件仅 `customLevel === 2`，但组合模式切换时 `customLevel` 可能仍为 1
- **修复**: 改为 `needL2 = customLevel === 2 || savedCombos.some(c => c.level === 2)`

### Bug 3: 基钦相位名解析可能返回数字
- **根因**: `cyclePhaseMap` 中 `pName = ph.cycle_phase_name || ph.stage`，如果 `cycle_phase_name` 缺失，`ph.stage` 是数字 1-4，`phaseColor(3)` 不匹配任何名称
- **修复**: 增加完整映射兜底：`ph.stage_name || KITCHIN_NAMES[ph.stage]`，朱格拉/库兹涅茨同理用 `MACRO_NAMES[ph.phase]`
- 注：用户报告"宏观基钦显示主动？但其他部分又显示被动补库"可能与此相关

## 新增：行业主线识别 MCP 工具（3个）

在 `deep_fusion/tools/industry.py` 中新增：

| 工具名 | 功能 | 参数 | 耗时 |
|--------|------|------|------|
| `industry_themes` | 相关性聚类+动量+资金流→当前市场主线 | window/n_clusters/corr_method | ~1s |
| `industry_themes_dcc` | DCC-GARCH时变条件相关 | window | ~30s |
| `industry_themes_causality` | Granger因果+龙头行业识别 | window/max_lag | ~60s |

### 返回格式
全部返回 JSON，核心字段：
- `industry_themes`: themes(评分/趋势/动量/资金流/龙头股) + momentum_ranking + pca_top_contributors
- `industry_themes_dcc`: dcc_params + latest_corr_top + corr_change_top
- `industry_themes_causality`: leading_industries + lagging_industries + top_causal_pairs

### 主线评分公式
score = 0.4×归一化簇内相关 + 0.35×归一化动量(5d) + 0.25×归一化资金净流入

### 趋势判定
- rolling_correlation 近期变化 > 0.02 → "strengthening"
- < -0.02 → "weakening"
- 其余 → "stable"

### 数据流
industry_db.get_daily_codes → get_daily(收盘价) → pct_change → 收益率矩阵
+ get_classify(ths) 做code→name映射
+ get_fund_flow 资金流信号

### 实测结果（90行业/120日窗口）
- 5个主线簇，其中1个大簇(80行业)反映A股整体高相关性
- 动量TOP: 电力(7.4%)、煤炭(7.3%)、白酒(5.6%)
- 银行+白酒、保险+贵金属 趋势为 strengthening

## 修 PCA 方向 + 去市场beta聚类

用户发现 PC3 里半导体和影视院线"在同一组"，实际是按绝对值排序丢失方向信息：
- 半导体 PC3=-0.115, 影视院线 PC3=+0.114 → 方向相反，PC3捕捉的是"消费vs科技"对冲

修改 `correlation.py`:
1. `pca_loadings` 的 `top_contributors` 改为分 positive/negative 方向输出，保留 by_abs 兼容
2. `identify_themes` 新增 `remove_market_beta=True`，聚类前先从收益率去除 PC1 分量
   - A股 PC1 解释 ~54% 方差=市场beta，不去的话80/90行业挤一簇
   - 去PC1后残差相关中位数从0.576降到~0.2，行业特质因子才显现
3. `_label_themes` 代表行业改取 PC2 载荷最大（PC1是beta，PC2+才区分特质）

修改 `industry.py`:
- `pca_top_contributors` 输出适配新格式 positive/negative

实测效果（90行业/120日）:
- 修改前: 5簇中1个80行业大簇（无意义）
- 修改后: 5簇分别为16/5/10/20/39行业，主线清晰: 半导体+电子、电力+新能源、影视+传媒、油气+资源、保险+消费
