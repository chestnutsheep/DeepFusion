# 2026-06-21 前端 Bug 修复与功能增强

## 修复清单

### BUG-1: DataChart 对数Y轴切换不生效 (P0)
- **根因**: useEffect cleanup 每次 `chart.dispose()`，导致图表实例被销毁后重新 init，新实例的 setOption 合入时缺少完整配置
- **修复**: 改为 `notMerge: true` 全量替换 option，不每次 dispose，只在组件卸载时 dispose；用 `echarts.getInstanceByDom()` 获取已有实例而非每次 `echarts.init()`
- **文件**: `dashboard/src/components/common/DataChart.jsx`

### BUG-7: 侧边栏日期区域基钦相位重复 + 改为日期/星期/时间/市场状态
- **修复**: 删除日期区域的基钦相位行，改为显示：日期、星期几、24小时制时间、市场状态（休市/交易中/已收盘/美盘交易中/盘前）
- **市场状态逻辑**: A股交易时间9:30-11:30/13:00-15:00，美盘21:30-04:00(北京时间)，每分钟更新
- **文件**: `dashboard/src/components/Sidebar.jsx`

### BUG-2 续: treemap 点击跳转路由不切换 (P0) — 已修复并验证
- **根因**: `ConstituentDrilldown` 的 click handler 只调用了 `store.setActiveTab('micro')`，**没有调用 `navigate('/micro')`**
  - 项目使用 BrowserRouter + Routes，URL 路由才是决定页面渲染的机制
  - store 状态 `activeTab` 不会触发路由切换，URL 保持 `/meso`，StockPanel 根本不会挂载
- **修复**: 在 `ConstituentDrilldown` 中引入 `useNavigate()`，click handler 中增加 `navigate('/micro')`
- **额外修复**: store 暴露到 `window.__APP_STORE__` 便于调试和端到端测试
- **文件**: `MesoLayout.jsx`, `store/index.js`
- **验证**: Playwright 端到端测试全链路通过：
  1. 热力图点击 → 二级行业下钻 ✅
  2. 二级行业 treemap 点击 → 成份股下钻（焦炭II → 7只成份股）✅
  3. 成份股 treemap 点击美锦能源(000723) → navigate('/micro') ✅
  4. StockPanel 自动加载 000723 K线+财务指标 ✅
