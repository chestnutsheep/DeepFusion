## 申万二级行业成分股下钻功能（TDD驱动）

### 需求
用户希望从申万二级行业树状图进一步点击下钻，查看该行业成分股的当日涨跌幅数据。

### 实现
1. **后端 `industry_sw.get_constituents_with_quotes()`**（`deep_fusion/data/sources/industry_sw.py`）
   - 聚合 `get_constituents()` (ak.index_component_sw) + `ak.stock_zh_a_spot_em` (全A实时行情)
   - LEFT JOIN on stock_code → 补充 change_pct / price / turnover / pe_dynamic / pb
   - 长期缓存 86400s（成分股+行情均用 86400 TTL）
   - 按 weight 降序排列，部分成分股无行情时显示 NaN

2. **MCP 工具 `industry_sw_constituents_detail`**（`deep_fusion/tools/industry.py`）
   - 参数：行业代码(必填) + limit(默认50)
   - 返回 CSV，含 stock_code / stock_name / weight / change_pct / price / turnover / pe_dynamic / pb

3. **前端 `ConstituentDrilldown` 组件**（`dashboard/src/components/Meso/MesoLayout.jsx`）
   - IndustryDrilldown 的 treemap 新增点击事件 → 设置 constituentTarget 状态
   - ConstituentDrilldown 组件调用 industry_sw_constituents_detail，展示可排序表格
   - 支持按代码/名称/权重/涨跌幅/价格/换手率/PE/PB 排序
   - tooltip 增加"点击查看成分股"提示
