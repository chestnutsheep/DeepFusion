## 局域网/内网穿透现状检查

项目当前**无内网穿透工具**（ngrok/frp/cloudflare tunnel 均未配置），但已具备局域网访问基础：
- 后端 `serve.py`: uvicorn `host='0.0.0.0'` 监听所有网卡
- 前端 `start_all.sh`: `vite --host 0.0.0.0` + `vite.config.js` 中 `host:true`, `allowedHosts:true`
- CORS: `allow_origins=['*']`
- 同局域网设备可通过 `<本机IP>:8080` 访问前端，`:5173/api` 访问后端
- Docker compose 无端口映射到公网配置
- proxy target 硬编码 `localhost:5173`

## 代理策略：NO_PROXY 排除国内数据源

`serve.py` 添加 `NO_PROXY` 环境变量，排除不需要代理的国内域名，使申万/同花顺/新浪/雪球/巨潮/NBS 直连，东方财富(`_em`)和国外数据源(FRED/WB)继续走代理。

排除列表：`swsresearch.com, 10jqka.com.cn, sina.com.cn, xueqiu.com, cninfo.com.cn, stats.gov.cn, data.stats.gov.cn, localhost, 127.0.0.1`

原因：全局代理导致申万(swsresearch.com)请求 ProxyError/SSLEOFError，国内网站走代理反而出错。

## 期货工具 symbol 参数修复

`deep_fusion/tools/futures.py` 中四个期货工具的 akshare API 参数格式各不相同，原代码统一用 `FUTURES_SYMBOLS` 把中文名转成合约代码（如"螺纹钢"→"RB"），导致三个 API 报错。

### 根因
akshare 期货接口的 symbol 参数格式不统一：
| 函数 | 期望格式 | 原代码传入 | 结果 |
|------|----------|-----------|------|
| `futures_main_sina` | 新浪编号 `"RB0"` | `"RB"` | `Expected object or value` |
| `futures_inventory_em` | 中文名 `"螺纹钢"` | `"RB"` | `请输入正确的 symbol` |
| `futures_spot_price` | 合约代码 `["RB"]` | `["RB"]` | 本来就对 |
| `futures_hold_pos_sina` | symbol=持仓类型, contract=合约代码 | symbol=品种代码 | 逻辑错误 |

### 修复
1. `FUTURES_SYMBOLS` 改为 `{"中文名": {"code": "RB", "sina": "RB0"}}` 双字段映射，品种从 18 个扩展到 49 个
2. `futures_prices`: 用 `info["sina"]` 传给 `futures_main_sina`
3. `futures_inventory`: 直接传中文名给 `futures_inventory_em`
4. `futures_basis`: 用 `info["code"]` 传给 `futures_spot_price` 的 `vars_list`
5. `futures_positions`: 新增 `position_type` 参数（成交量/多单持仓/空单持仓），传给 `futures_hold_pos_sina` 的 symbol；contract 用合约代码
6. `akshare_adapter.py` 中期货接口加注释说明各函数期望的参数格式

### 验证
- `futures_prices(symbol='螺纹钢')` ✅ 返回 OHLCV CSV
- `futures_inventory(symbol='螺纹钢')` ✅ 返回库存 CSV

## 对数化/归一化图表处理 + 期货标的物更新

### DataChart.jsx 增强
新增三个 props：
- `yAxisType`: `'value'`(默认线性) | `'log'`(对数) — ECharts yAxis.type
- `normalize`: `false`(默认) | `true` — 归一化到基期=100
- `normalizeBase`: `'first'`(默认) | `'last'` — 归一化基期选择

归一化逻辑：对每个 series 的数据，取首个/末尾有效值作为基期，`p(t)/p(base)*100`。

### 对数Y轴应用场景
| 场景 | 文件 | yAxisType |
|------|------|-----------|
| 期货价格走势 | FuturesPanel.jsx, GlobalPanel.jsx FuturesSection | log |
| 期货库存变化 | 同上 | log |
| 股票K线收盘价 | StockPanel.jsx | log |
| 黄金现货走势 | GlobalPanel.jsx MetalsSection | log |
| 白银现货走势 | 同上 | log |
| BTC 日线 | GlobalPanel.jsx CryptoSection | log |
| ETH 日线 | 同上 | log |

### 归一化对比功能
三个 Section 各增加"归一化对比"切换按钮：
- **MetalsSection**: 合并黄金+白银数据到同一时间轴，normalize=true
- **CryptoSection**: 合并 BTC+ETH 数据到同一时间轴，normalize=true
- **ForexSection**: 合并 USDCNY+EURUSD 数据到同一时间轴，normalize=true

切换按钮在"归一化对比"模式时显示金色背景，"绝对值"模式时透明。

### 期货标的物更新
前端和后端默认品种从"螺纹钢"改为"原油"，快捷按钮改为战略资源/局势敏感标的：
