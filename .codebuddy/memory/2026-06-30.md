## 2026-07-01 季节性相关性分析功能

### 后端新增
- `correlation.py` 新增 `seasonal_correlation()` 函数（第6节）：按(年,月)切片计算行业间相关系数，跨年横向比较，输出：
  - `monthly_corr`: 各(年,月)切片的扁平化行业对相关系数
  - `monthly_avg_corr`: 按月聚合的多年平均相关系数
  - `seasonal_profile`: 每对行业→各月份平均相关系数
  - `peak_months` / `valley_months`: 峰/谷月份及对应值
  - `seasonal_strength`: 波动幅度(峰-谷)
  - `heatmap_data`: 供前端 ECharts heatmap 渲染的数据
- `industry.py` 新增 `industry_seasonal_corr` MCP 工具：
  - 参数: `industries`(逗号分隔行业名), `corr_method`, `min_years`
  - 加载全量数据（从 meso_industry_daily），至少需要 min_years 年数据
  - 异步执行（CPU密集丢入 executor）
  - 返回 JSON + readable_summary

### 前端新增
- `SeasonalCorrelation.jsx` 新建 — 季节性相关性交互分析面板：
  - 行业选择器（搜索+多选+预设组合：地产链/消费链/周期链/科技链）
  - 月份×行业对 ECharts heatmap（颜色=联动强度）
  - 季节性波动幅度排行表（波幅=峰-谷）
  - 行业对剖面折线图（勾选行业对查看月度联动曲线）
